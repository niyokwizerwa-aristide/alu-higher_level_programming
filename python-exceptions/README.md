# Python - Exceptions

This directory contains Python scripts about exception handling.

## Tasks

- 0-safe_print_list.py: prints x elements of a list safely
- 1-safe_print_integer.py: prints an integer with str.format() and returns True, or False if it is not an integer
- 2-safe_print_list_integers.py: prints the first x elements of a list and only integers
- 2-safe_print_list_integers.py: prints the first x elements of a list and only integers
- 3-safe_print_division.py: divides 2 integers and prints the result
- 4-list_division.py: divides element by element 2 lists
- 5-raise_exception.py: raises a type exception
- 6-raise_exception_msg.py: raises a name exception with a message
- 100-safe_print_integer_err.py: prints an integer and writes the error to stderr if it is not one
- 101-safe_function.py: executes a function safely
